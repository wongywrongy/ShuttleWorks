Compact tabular code chip for match codes, round codes, seeds, and event ranks. The lightweight replacement for filled pills inside tables.

```jsx
<Tag>MS1</Tag>
<Tag tone="bracket">QF1</Tag>
<Tag dashed>unseeded</Tag>
```

- `tone`: `accent` (Meet blue tint) · `plain` (no fill) · `bracket` (violet tint)
- `dashed`: outline-only for empty/placeholder slots.
- Always renders tabular figures so codes align in a column.
