Compact metric tile for the Run summary band and dashboards. Big tabular value over an uppercase caption; tinted border by tone.

```jsx
<MetricTile value="3/12" label="Done" />
<MetricTile value="3" label="Playing" tone="live" />
<MetricTile value="1" label="Late" tone="called" />
```
Lay out in a `display:flex; gap:10px` row — tiles flex to fill.
