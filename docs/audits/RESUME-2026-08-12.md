## Standing constraints — these have all bitten this session

- **Parallel agents share one git index.** `git add` + `git commit` sweeps a peer's staged files into
  your commit. It happened twice. **Use `git commit -m "..." -- <paths>`.**
- **Never `git commit --amend`** in a shared checkout. One landed on a peer's commit and needed an
  `update-ref` repair.
- **Never use PowerShell here-string syntax (`@'…'@`) inside a Bash tool call.** It is passed
  literally and corrupts the commit subject. `55d5998` and one other carry a stray `@`; cosmetic,
  left alone.
- **One browser, one agent.** Six parallel audits collided on a shared Playwright instance and had to
  be serialised into a FIFO queue mid-run.
- **File-modification time is not a liveness signal.** An agent mid-investigation looks idle; I pulled
  its browser window on that basis and cost it a finding.
- **Never `git add`** `backend/app/dependencies.py`, `backend/services/auth.py` (CRLF-only noise, empty
  content diffs), `skills-lock.json`, `.codex/`, `.github/agents|hooks|skills/`.
- Zero client JS on the entrant tier is a **product commitment** (`entrant/PRODUCT.md`), enforced by a
  blocking 4 KB page-weight gate and `script-src 'self'`.
- **Every control owes an executed mutation.** 13+ "controls that cannot fail" were found in this
  program, and the Gantt fix shipped green on a test whose values were chosen to clear the very
  threshold it was meant to exercise.
